# Cute Hermes Skills 使用說明（給使用者）

這個 repo 提供兩個 Hermes skill：

| skill | 用途 |
|-------|------|
| `outlook-com` | 讀取／搜尋電腦上 **Outlook（傳統版）** 的學校信箱（cute.edu.tw） |
| `gmail-oauth` | **gm 帳號**（gm.cute.edu.tw）：gm 信箱 讀／搜尋／寄信／回信，gm 雲端硬碟 列出／搜尋／讀取／下載／上傳／整理 |

---

## 1. 安裝與更新（每台電腦，同一套流程）

第一次安裝、要更新到新版、或 skill 怪怪的時候，都做這一段。

### 方法 A：一句話叫 agent 照做（最簡單）

在 Hermes 開一個對話，貼上：

```
請讀取 https://raw.githubusercontent.com/shein888/cute-hermes/main/AGENT-SETUP.md 並逐步照做
```

agent 會依 [AGENT-SETUP.md](../AGENT-SETUP.md)：
0. 先告訴你：「這是中國科大 CUTe Hermes專屬OA skill套件, 提供Outlook API 及GM帳號授權綁定功能, 請放心下載更新」
1. **先檢查**：目前裝的版本、這台電腦綁的 gm 帳號和權限（只讀，不會動到授權）、有沒有傳統版 Outlook。
2. 提醒「更新後對話會重新整理, 還請見諒」，然後**移除舊版 → 安裝新版 → 確認版本。**
3. 回報「已下載並更新完成」和結果（版本、gm 授權、Outlook），並請你開一個新的對話（`/new`）。

如果 agent 說沒辦法讀取網址，改用下面的「方法 A-2」。

### 方法 A-2：把指令整段貼給 agent

```
請在終端機逐行執行，出現 not found 或 not a hub-installed skill 是正常的，繼續下一行，不要重啟 Hermes：
hermes skills tap add shein888/cute-hermes
hermes skills uninstall outlook-com --yes
hermes skills uninstall gmail-oauth --yes
hermes skills install shein888/cute-hermes/skills/outlook-com --yes
hermes skills install shein888/cute-hermes/skills/gmail-oauth --yes
hermes skills list
最後告訴我 outlook-com 和 gmail-oauth 的版本號
```

### 方法 B：自己在 PowerShell 執行

如果方法 A 讓 Hermes 斷線（畫面出現「Failed to fetch」），或 agent 說沒有權限，就自己開 **PowerShell** 執行：

```powershell
hermes skills tap remove https://github.com/shein888/cute-hermes
hermes skills tap add shein888/cute-hermes
hermes skills uninstall outlook-com --yes
hermes skills uninstall gmail-oauth --yes
hermes skills install shein888/cute-hermes/skills/outlook-com --yes
hermes skills install shein888/cute-hermes/skills/gmail-oauth --yes
hermes skills list
```

### 方法 C：Hermes Desktop 的安裝連結

按 Win+R，貼上後按 Enter，在 Hermes 跳出的視窗按 **Install**（兩個都要）：

```
hermes://skill/install?identifier=shein888%2Fcute-hermes%2Fskills%2Foutlook-com
hermes://skill/install?identifier=shein888%2Fcute-hermes%2Fskills%2Fgmail-oauth
```

### 裝完之後

- 版本要對得上 [CHANGELOG](../CHANGELOG.md) 的最新版本。
- **一定要開一個新的對話**（指令列輸入 `/new`，或 Desktop 開新對話分頁）再使用。
  Hermes 在對話開始時就決定這個對話看得到哪些 skill，對話中讀過的舊版說明也會留著，
  所以舊對話可能看不到新 skill、或照舊版的方式做事。

### 為什麼要「先移除再安裝」？

已經裝過的 skill 再執行 `hermes skills install` 會被拒絕（`already installed … Use --force`），
就算舊版號比較小也一樣；`hermes skills update` 也可能回答「No updates available」。
先 `uninstall` 再 `install` 最確定會拿到 GitHub 上的最新版。
移除 skill **不會**刪掉 gm 授權，也不會動到 Outlook 的信件或設定。

## 2. 怎麼跟 agent 說

### Outlook（學校信箱 cute.edu.tw）

- 「幫我查 Outlook 最近三天的信」
- 「Outlook 有沒有 prac 寄來、跟 114-2 有關的信」
- 「Outlook 收件匣 02-圖資中心 資料夾今天的信」

### gm 信箱

- 「幫我看 gm 信箱最近 5 封信」
- 「gm 信箱有沒有未讀的信」
- 「幫我回覆這封信：收到，謝謝」（寄出前 agent 會先給你確認）

### gm 新信通知（有新信主動告訴你）

平常 agent 只有在你叫它查信時才會去看 gm 信箱。想要新信一進來就被通知，跟 agent 說：

- 「gm 有新信要通知我」

它會設定一個排程：每 5 分鐘檢查一次，有新信就在這個對話（或你指定的 Bot Chat／Telegram）發通知，
列出寄件人和主旨；沒有新信就不出聲，也不耗用 AI 額度。

- 只通知設定之後新進來的信，之前的不會重報。
- 電腦關機或 Hermes 關掉時會暫停，下次開啟時補報期間的新信。
- 停止：「停止 gm 新信通知」；改頻率：「gm 新信通知改成每 10 分鐘」。
- 這不是即時推播，最多約 5 分鐘延遲。

### gm 雲端硬碟

- 「把 gm 雲端硬碟最近的檔案列出來」
- 「在 gm 雲端硬碟找個資盤點清冊」
- 「讀一下這份 Google 文件的內容」
- 「把這個檔案下載到桌面」
- 上傳、改名、搬移、刪除（丟到垃圾桶）之前，agent 都會先告訴你會改什麼，等你同意。
  刪除只會丟到垃圾桶，30 天內可以救回來。

### 想確認狀態時

- 「gm 授權狀態」→ 會顯示這台電腦綁的是哪個 gm 帳號、有沒有信箱和雲端硬碟權限、何時授權。
- 「hermes skills list 裡 outlook-com 和 gmail-oauth 是幾版？」

## 3. gm 帳號授權（第一次會發生）

- **不用自己去設定什麼。** 第一次叫 agent 用 gm 信箱或雲端硬碟時，它會給一個 Google 授權網址。
- 點網址 → 用 **自己的 gm.cute.edu.tw 帳號** 登入 → 按「**允許**」→ 回 agent 說「好了」。
- 一次授權同時包含 gm 信箱和雲端硬碟。每個人只能看到自己的信箱和雲端硬碟。
- skill 之後新增功能時，用到新功能的那一次 agent 會再給一個網址，按「允許」補上即可，**不需要解除綁定**。
- 授權存在這台電腦使用者自己的資料夾，移除／重裝 skill 不會清掉。

只有這些情況要重新授權：

| 情況 | 跟 agent 說 |
|------|-------------|
| 換一台電腦 | 不用特別說，第一次使用時 agent 會給網址 |
| 同一台電腦要改用另一個 gm 帳號 | 「gm 帳號登出，改用別的帳號」 |
| 改過 gm 密碼、或在 Google 帳戶裡移除過授權 | 「gm 帳號登出，重新授權」 |

如果按了「允許」後瀏覽器顯示「無法連線」，把網址列整串網址（`http://127.0.0.1:...`）複製給 agent，跟它說「這是授權後的網址，幫我用 import-code 完成」。

## 4. 常見問題

| 狀況 | 原因／處理 |
|------|-----------|
| agent 說「skills list 沒有 Outlook 相關的 skill」 | 還沒安裝，或裝到舊版（舊版在 WSL 上會被隱藏）。照第 1 節重裝。 |
| agent 要你提供 client_id／secret，或要你去 Google Cloud Console 加 redirect URI | skill 是舊版。照第 1 節重裝，再開新對話。 |
| agent 說要「修改 gmail_oauth.py 的 SCOPES」或任何 skill 程式 | **不要讓它改。** 改過的 skill 之後就無法自動更新。照第 1 節重裝。 |
| gm 信件主旨顯示成 `=?UTF-8?B?...` 或寄件人和主旨對不上 | skill 是舊版，或 agent 自己寫程式讀信。重裝後開新對話，請它「直接貼出 skill 指令的原始輸出」。 |
| Hermes 畫面顯示「Failed to fetch」、重啟失敗 | 從系統匣把 Hermes 完全結束再開；不行就在 PowerShell 執行 `hermes gateway restart`。安裝 skill 改用第 1 節方法 B。 |
| Outlook 查不到、卡住、或報錯 | 跟 agent 說「執行 outlook-search 的 -Diagnose，告訴我原因」，對照下表。 |

### Outlook 診斷結果對照

| 診斷顯示 | 原因／處理 |
|----------|-----------|
| `NewOutlookInstalled: True`、`ComRegistered: False` | 這台用的是「**新版 Outlook**」，不支援。把 Outlook 右上角「新版 Outlook」開關關掉，改回傳統版。 |
| `ComRegistered: False` | 沒有安裝傳統版 Outlook（Microsoft 365 桌面版）。 |
| `80080005` | Outlook 和 Hermes 一個是「以系統管理員身分執行」、一個不是。兩個都用一般方式開啟。 |
| `AntivirusRegistered: NONE`，或搜尋一直卡住 | Outlook 跳出隱藏的「有程式嘗試存取電子郵件地址」安全提示。請資訊人員檢查防毒狀態或 Outlook 信任中心的「程式存取」設定。 |
| `ExecutionPolicy: MachinePolicy=AllSigned／Restricted` | 群組原則禁止執行 PowerShell 腳本，請資訊人員處理。 |
| Outlook 開啟時要你選設定檔 | 控制台 → 郵件 → 顯示設定檔 → 選「一律使用這個設定檔」。 |
